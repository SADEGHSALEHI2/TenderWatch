# مناقصه‌یاب (TenderWatch)

اپ اندروید برای پیدا کردن مناقصه‌ها و قراردادهای دولتی مربوط به لوله، اتصالات، پلی‌اتیلن، پی‌وی‌سی، آبرسانی و فاضلاب.
این اپ سرور ندارد و خود گوشی مستقیم سایت‌ها را می‌خواند. پس گوشی باید به اینترنت ایران وصل باشد (بدون VPN خارجی).

## منابع

| منبع | چه چیزی | روش |
|---|---|---|
| ستاد (etend.setadiran.ir) | همه فراخوان‌های عمومی فعال (حدود ۴۰۰۰ مورد) | لیست عمومی صفحه اول سامانه (JSON). همه موارد خوانده و در گوشی با کلمات کلیدی فیلتر می‌شوند |
| پایگاه اطلاعات قراردادهای کشور (cdb.mporg.ir) | قراردادهای منعقدشده: کارفرما، طرف قرارداد (برنده)، مبلغ و تاریخ‌ها | جستجوی پیشرفته سایت با هر عبارت و از تاریخ مشخص |

اسناد و جزئیات کامل مناقصه در ستاد پشت کد امنیتی (کپچا) است. برای همین دکمه «مشاهده در سامانه ستاد» صفحه ستاد را داخل اپ باز می‌کند و کد امنیتی را خودتان وارد می‌کنید.

## امکانات

- بررسی خودکار در پس‌زمینه. ستاد به‌طور پیش‌فرض هر ۳ ساعت و قراردادها هر ۲۴ ساعت بررسی می‌شوند. برای موارد جدید اعلان می‌آید.
- سه زبانه: مناقصات، قراردادها و نشان‌شده‌ها. جستجو در فهرست و فیلتر «فقط مهلت‌دار».
- صفحه جزئیات با همه فیلدها، کپی شماره، اشتراک‌گذاری و باز کردن صفحه سایت.
- همه کلمات کلیدی، کلمات استثنا و فاصله بررسی از صفحه تنظیمات قابل تغییر است.

## ساخت APK با GitHub

1. در GitHub یک مخزن (repository) جدید بسازید، مثلاً `TenderWatch`.
2. محتوای همین پوشه را در آن قرار دهید. پوشه `.github` را هم حتماً بفرستید. برای این کار یکی از این دو راه را انتخاب کنید:
   - **GitHub Desktop:** مخزن را clone کنید، فایل‌ها را در آن کپی کنید و Commit و Push بزنید.
   - **سایت GitHub:** گزینه Add file → Upload files را بزنید و همه فایل‌ها و پوشه‌ها را بکشید و رها کنید.
3. با هر Push، در زبانه **Actions** یک build به نام «Build APK» اجرا می‌شود که حدود ۵ دقیقه طول می‌کشد.
4. بعد از سبز شدن build، روی آن بزنید و از بخش **Artifacts** فایل `TenderWatch-apk` را دانلود کنید. فایل `app-debug.apk` داخل آن را روی گوشی نصب کنید. نصب از منابع ناشناس باید اجازه داده شود.

اگر build قرمز شد، لاگ خطا را از Actions کپی کنید تا اصلاح شود.

## نکته‌ها

- اولین بروزرسانی همه مناقصه‌های فعال ستاد را می‌خواند (حدود ۲۰ تا ۲۵ مگابایت). بروزرسانی‌های بعدی فقط موارد جدید را می‌خوانند.
- جستجوی قراردادها سنگین است: برای هر عبارت حدود ۷ مگابایت. سایت در هر صفحه فقط ۱۰ ردیف می‌دهد و فرم بزرگی دارد. فهرست عبارت‌ها را کوتاه نگه دارید.
- بعد از تغییر کلمات کلیدی، بروزرسانی بعدی همه موارد را از اول بررسی می‌کند.
- برای اینکه اندروید بررسی پس‌زمینه را متوقف نکند، بهینه‌سازی باتری را برای این اپ خاموش کنید.

## ساختار کد

```
app/src/main/java/ir/tenderwatch/
  source/SetadSource.kt   خواندن لیست ستاد
  source/CdbSource.kt     جستجو در پایگاه قراردادها (ASP.NET postback)
  sync/SyncRunner.kt      یک دور بروزرسانی همه منابع + فیلتر کلمات
  sync/SyncWorker.kt      اجرای دوره‌ای در پس‌زمینه (WorkManager)
  util/Text.kt            یکسان‌سازی متن فارسی، تطبیق کلمات، تاریخ شمسی
  data/                   تنظیمات و ذخیره موارد (فایل JSON)
  ui/                     صفحه‌ها (Jetpack Compose)
```

## مراحل بعدی

افزودن منابع دیگر:
- سایت مناقصات گل‌گهر، مس سرچشمه و شرکت‌های تابعه
- شرکت‌های آب و فاضلاب و آب منطقه‌ای
- سامانه‌های تجمیع مناقصه
- آگهی روزنامه‌ها

هر منبع یک کلاس جدید در `source/` است.
